# dart-kospi-financials

KOSPI(코스피) 상장기업의 이름을 입력하면 금융감독원 DART Open API에서 재무제표를 자동으로 수집하여, 최근 12분기 분기 재무제표와 최근 5개년 연간 재무제표를 각각 별도 시트에 정리한 엑셀 파일을 생성합니다.

## 구성 요소

| 컴포넌트 | 이름 | 역할 |
|---|---|---|
| Skill | `dart-financial-extractor` | DART API 연동, 분기 실적 계산, 엑셀 작성 전체 워크플로우를 정의 |

이 스킬은 내부적으로 Cowork의 코드 실행 환경(bash/python)을 사용해 `scripts/` 폴더의 스크립트를 순서대로 호출합니다:
- 단일 기업: `corp_code_lookup.py` → `fetch_financials.py` → (선택) `fetch_extra_disclosures.py` + `fetch_stock_price.py` → `build_workbook.py`
- 여러 기업 비교: 마지막 단계만 `build_comparison_workbook.py`로 대체 (투자분석 시트는 비교 파일에는 포함되지 않습니다)

엑셀 작성 단계에서는 Anthropic 기본 제공 `xlsx` 스킬의 규칙(서식, 수식 사용, recalc 검증)을 함께 따릅니다.

## 필수 설정 (Setup)

이 플러그인을 사용하려면 **DART Open API 인증키**가 필요합니다.

1. https://opendart.fss.or.kr/ 에서 발급받은 인증키(40자리 영숫자)를 준비합니다.
2. 별도 등록 없이, Cowork 대화창에서 스킬을 처음 사용할 때 인증키를 물어보면 그때 붙여넣으면 됩니다. (Cowork는 격리된 실행 환경이라 Windows/macOS의 OS 환경 변수를 상속받지 못하므로, 이 플러그인은 OS 환경 변수 등록 대신 대화 중 값을 받아 매 스크립트 호출 시 `--api-key` 인자로 전달하는 방식을 씁니다.)
3. 인증키는 절대 스킬 파일이나 산출물(엑셀, 로그)에 직접 하드코딩하지 않습니다. 각 스크립트는 `--api-key` 인자(또는 로컬 Claude Code 환경이라면 `DART_API_KEY` 환경 변수)로만 읽습니다.
4. 참고: `--api-key`로 넘긴 값은 편의를 위한 트레이드오프로 해당 대화의 명령 실행 기록에 남습니다. 여러 사람과 공유하는 대화나 세션이라면 주의하세요.

## 사용법

Cowork 채팅에서 아래와 같이 요청하면 스킬이 트리거됩니다.

```
삼성전자 재무제표 뽑아줘
LG화학 DART 재무제표 자동화 실행해줘
카카오 최근 12분기, 5개년 재무제표 엑셀로 만들어줘
HD한국조선해양 년 분석해줘        → 연간 시트만 담은 파일 1개(재무제표+투자분석)
HD한국조선해양 분기 분석해줘      → 분기 시트만 담은 파일 1개(재무제표+투자분석_분기추정, v0.11.0부터)
```

"년"/"분기"를 명시하지 않으면 기존처럼 한 파일에 분기+연간 다 담아 만듭니다.

**v0.11.0부터**: "분기 분석해줘"도 재무제표만 나오는 게 아니라, 분기 누적 공시를 연간으로 환산(FY_E)한 "투자분석_분기추정" 시트까지 자동으로 포함됩니다. 최신 분기 하나의 실적을 그대로 연간화하면 PER 등이 4~5배씩 왜곡되는 문제를, 전년 동기 대비 성장률을 계정별로 독립 적용해 해결했습니다. 자세한 계산 방식은 `skills/dart-financial-extractor/SKILL.md`의 "v0.11.0 (분기 연환산)" 참고.

### 여러 기업 처리 (v0.3.1부터)

- **단순 나열** (비교 의도 없음): 기업마다 별도 엑셀 파일을 만듭니다.
  ```
  삼성전자, LG화학, 카카오 재무제표 뽑아줘
  → 삼성전자_20260805.xlsx, LG화학_20260805.xlsx, 카카오_20260805.xlsx (각각 별도 생성)
  ```
- **"비교" 표현 포함**: 한 엑셀 파일 안에 여러 기업을 나란히 비교합니다.
  ```
  삼성전자, LG화학, 카카오 비교해줘                → "삼성전자, LG화학, 카카오 비교_20260805.xlsx" (분기+연간 둘 다)
  삼성전자, LG화학, 카카오 년 분석해줘 (비교 의도)   → "...비교_연간_20260805.xlsx" (최근5년 비교 시트만)
  삼성전자, LG화학, 카카오 분기 분석해줘 (비교 의도) → "...비교_분기_20260805.xlsx" (12분기 비교 시트만)
  ```
  회사마다 상장/공시 이력이 달라 보유 기간이 다를 수 있는데, 이 경우 전체 기업의 기간을 합집합으로 맞추고 특정 기업이 데이터가 없는 구간은 0으로 지어내지 않고 그래프에서 공백(끊김)으로 표시합니다.

  비교 파일은 눈에 보이는 시트가 **`12분기 비교`, `최근5년 비교` 2개**뿐입니다. 각 시트 상단에 지표×회사 데이터 표, 그 아래 지표 하나당 꺾은선 차트 하나(회사=계열, 비율 포함 전부 꺾은선)가 총 19개 이어집니다. 회사별 원자료·계산 시트는 감사용으로 남아있지만 숨김 처리됩니다.

## 산출물 — 단일 기업

- 파일명: `[기업명][_연간|_분기]_[YYYYMMDD].xlsx` (`--period` 옵션에 따라 접미사가 붙는다. "년"/"분기" 언급 없이 요청하면 접미사 없이 기존처럼 한 파일에 다 담긴다)
- 시트 1: `분기_재무제표` — 최근 12개 분기의 재무상태표·손익계산서·현금흐름표 (`--period quarterly`/`both`에서만)
- 시트 2: `연간_재무제표` — 최근 5개 사업연도(사업보고서 기준)의 재무상태표·손익계산서·현금흐름표 (`--period annual`/`both`에서만)
- 시트 3: `지표_분기` — 분기 기준 추세 지표 표 **+ 표 오른쪽(I열부터)에 임베드된 차트**(꺾은선 5개·막대 1개). v0.9.5부터 `차트_분기` 별도 시트 없이 이 안에 통합됨(지표_연간과 동일한 방식)
- 시트 4: `지표_연간` — 연간 기준 추세 지표 표 **+ 표 오른쪽(I열부터)에 임베드된 차트**(꺾은선 5개·막대 1개). v0.7.0부터 `차트_연간`이라는 별도 시트가 없어지고 이 안에 통합됨
- 시트 5: `투자분석` — 연간 데이터 기반이라 `--period annual`/`both`에서만 생성됨
- 시트 6: `원본데이터` (숨김) — 감사용 원본 값

| D. 청산가치 | 최신 연도 기준 조정자산(현금·유가증권 100%, 매출채권 85%, 재고·투자자산·유형자산 50%, 무형·기타유동자산 0%) − 총부채 |
| E. 현금전환주기(CCC) | 매출채권회수기간+재고자산처리기간−매입채무지불기간 |
| F. 잉여현금흐름(FCF) | 영업활동현금흐름−CAPEX, FCF마진(%) |
| G. 현금흐름 3단 구분 | 영업·투자·재무활동현금흐름 + 검증용 합계 |
| H. DuPont 분해 | ROE = 순이익률 × 총자산회전율 × 레버리지 |
| I. ROIC/NOPLAT(간이) | NOPLAT = 영업이익×(1−실효세율), 투하자본은 자기자본+비유동부채로 근사 |
| J. 자산·부채 구성비 변화(간이) | 유동/비유동 자산·부채가 총계 대비 몇 % |

| M. 배당·대주주·자기주식 | DART 추가 공시 4종에서 가져옴 |

### 필요한 추가 설정 — KRX Open API (선택)

E번 섹션(PER·PBR·PSR)만 KRX 데이터가 필요합니다. 없어도 나머지 섹션은 정상 작동합니다.

1. [openapi.krx.co.kr](https://openapi.krx.co.kr)에서 인증키를 발급받고, **마이페이지 → API 서비스 목록에서 "주식" 카테고리의 "유가증권 일별매매정보"를 별도로 찾아 이용 신청**합니다. (인증키 발급과 서비스별 이용 승인은 별개 절차입니다. "지수"나 다른 카테고리를 신청해도 이 서비스는 자동으로 열리지 않습니다.)
2. Cowork 설정 → 기능 → 코드 실행 → 네트워크 송신 허용 → 추가 허용 도메인에 `data-dbg.krx.co.kr`를 추가합니다 (실제 API 서버 도메인이며, 포털 도메인 `openapi.krx.co.kr`과 다릅니다).
3. `scripts/fetch_stock_price.py --auth-key <키> <종목코드> <YYYYMMDD>`로 연도별 연말 종가를 가져옵니다. "Unauthorized API Call"이 나면 1번의 서비스별 승인이 아직 안 된 것입니다.

## 두 번째 스킬 — investment-thesis-writer (v0.9.0부터)

"투자분석" 시트가 숫자 계산이라면, 이 스킬은 **글을 읽고 쓰는 정성 분석**입니다. 별도 시트 **"투자판단 종합"**을 첨부하셨던 "성공투자노트" 양식과 동일한 레이아웃으로 만듭니다.

```
삼성전자 투자판단 종합해줘
삼성전자 사업역량/경쟁우위/리스크 분석해줘
```

- DART 사업보고서의 "사업의 내용" 원문 텍스트 + **실시간 웹 리서치**(산업 동향, 경쟁사, 시장점유율, 최근 리스크 뉴스) + 기존 "투자분석" 시트의 정량 결과를 종합해 Claude가 직접 문장을 작성합니다.
- 산업분석·판매과정·생산과정·제품분석·경쟁우위·경쟁상황·리스크·예측가능기간·성장성예측·수익성예측·최종결론(지속가능기간·연평균예상수익률 포함) 섹션 + 장기(과거 5개년 실적+향후 예측) 재무추세 표로 구성됩니다.
- 과거 실적은 "지표_연간" 시트를 참조하는 수식, 예측 구간은 Claude가 제시한 성장률 가정을 복리 계산하는 수식으로 채워져 전부 감사 가능합니다(하드코딩 없음).
- ⚠️ 예측 구간은 시나리오이지 확정 실적이 아닙니다. 시트에도 각주로 표시되지만 대화에서도 한 번 더 안내합니다.
- 사전 조건: `dart-financial-extractor`로 먼저 "OO 년 분석해줘"(또는 v0.11.0부터 "OO 분기 분석해줘")를 실행해 "투자분석"(또는 "투자분석_분기추정") 시트가 있는 파일을 만들어 둬야 합니다. **분기 워크북이면 아래 두 스크립트 모두 `--period quarterly` 옵션을 붙여야 합니다** — 안 붙이면 "투자분석" 시트를 찾다가 에러가 납니다.

### 세 번째 시트 — 버핏멍거_가치평가 (v0.9.7 / investment-thesis-writer v1.4.0부터)

첨부하셨던 "워렌버핏과 찰리멍거" 자료를 코드화한 정량 가치평가 시트입니다.

```
삼성전자 내재가치 계산해줘
삼성전자 DCF 해줘
삼성전자 안전마진 확인해줘
```

- **A. 오너 어닝** = 당기순이익 + 감가상각비 − |CAPEX| (5개년 과거)
- **B. 그레이엄 내재가치 & 안전마진**: 자산기반(BPS×10)과 성장주기반(EPS×(8.5+2×기대성장률)) 두 가지 내재가치, 각각의 안전마진
- **C. 시장 내재 기대성장률 역산**: 현재 PER에 시장이 반영한 성장률 vs 실제 과거 성장률 비교
- **D. ROIC vs WACC 스프레드**: 경제적 해자의 정량적 증거
- **E. DCF 내재가치 계산기**: 할인율·영구성장률 가정 + 다년도 오너 어닝 예측 + 영구가치(TV) → 주당 내재가치·안전마진까지 전부 수식
- **F. 경제적 해자 체크리스트**: 9개 항목(경쟁우위·시장점유율·경영진·안전마진·가격전가력·신뢰성·규제경험·규모우위·네트워크효과)
- **G. 종합 결론**

과거 실적·비율은 "지표_연간"/"투자분석" 시트를 참조하는 수식이고, 할인율·성장률 가정과 해자 체크리스트만 Claude가 리서치해서 채웁니다. 기본 동작(`--outdir` 미지정)은 같은 파일에 시트를 추가해, 재무제표+투자분석+투자판단종합+가치평가가 파일 하나에 모두 모입니다.

## 분기 연환산 — 투자분석_분기추정 (v0.12.0부터)

"OO 분기 분석해줘"로 요청하면, `--period annual`(연간)에서 만드는 것과 동일한 구성의 시트를 분기 기준으로도 자동으로 만듭니다.

- **`연환산_재무제표`**(숨김), **`지표_연환산`**(숨김), **`투자분석_분기추정`**(표시) 3개 시트가 추가됩니다. 레이아웃은 연간_재무제표와 동일(연도 1컬럼)합니다.
- **이미 사업보고서가 나온 완결 연도는 추정하지 않고 실적 그대로** 씁니다 — `분기_재무제표`의 4개 분기 합과 정확히 일치합니다.
- **아직 사업보고서가 없는 최신 연도만** 추정합니다: 이미 공시된 분기는 실측 그대로, 아직 공시 안 된 분기는 "최신 공시 분기의 전년 동기 대비 증감율"을 그대로 적용해 추정합니다. 매출액이 +10%, 순이익이 +50%처럼 계정마다 성장률이 다르면 각자의 실제 비율이 각자에게만 반영됩니다.
- 예: 2026년 1분기가 2025년 1분기 대비 +50%라면, 2026년 2~4분기는 2025년 각 분기 실적 × 1.5로 추정하고, 4개 분기 합을 "2026(E)"로 표시합니다.

## 세 번째 스킬 — thesis-auditor (v0.11.0부터, 검수)

`투자분석`/`투자판단 종합`/`버핏멍거_가치평가`처럼 웹 서치·가정치·정성 텍스트가 섞인 산출물을, **사용자에게 전달하기 전에** 자동으로 검수합니다. 값을 고치지 않고 PASS/WARN/FAIL만 표시하는 게이트 역할입니다.

```
python skills/thesis-auditor/scripts/audit_workbook.py <xlsx 경로> \
    --thesis-content <thesis content.json> --valuation-content <valuation content.json>
```

- **그룹 A**: 수식 오류 셀, 회계항등식(자산=부채+자본), 현금흐름 3단 합계, 계정 매칭 실패 목록
- **그룹 B**: PER 상식범위, 시가총액/상장주식수 단위 정합성, 시장 내재 기대성장률 단위 혼동(과거에 실제로 났던 버그 유형들)
- **그룹 C**: 정량 등급과 정성 서술의 방향 모순(예: 재무건전성 D등급인데 "안정적"이라고 서술)
- **그룹 D**: DCF 할인율·영구성장률 등 가정 경계값
- **그룹 E**: 웹 리서치 출처(sources) 존재 여부, content.json의 회사명이 파일명과 일치하는지
- **그룹 Q**: 분기 연환산(FY_E/TTM) 파이프라인이 의도대로 만들어졌는지(v0.11.0부터, 위 "분기 연환산" 기능과 짝을 이룸)

`dart-financial-extractor`/`investment-thesis-writer`가 산출물을 만든 직후 자동으로 이어서 실행되는 게 기본 동작입니다. FAIL이 있으면 원인을 고쳐 앞 단계를 재실행하거나 사용자에게 확인을 받은 뒤에만 전달합니다.
