# dart-kospi-financials

KOSPI(코스피) 상장기업의 이름을 입력하면 금융감독원 DART Open API에서 재무제표를 자동으로 수집하여, 최근 12분기 분기 재무제표와 최근 5개년 연간 재무제표를 각각 별도 시트에 정리한 엑셀 파일을 생성합니다.

## 구성 요소

| 컴포넌트 | 이름 | 역할 |
|---|---|---|
| Skill | `dart-financial-extractor` | DART API 연동, 분기 실적 계산, 엑셀 작성 전체 워크플로우를 정의 |

이 스킬은 내부적으로 Cowork의 코드 실행 환경(bash/python)을 사용해 `scripts/` 폴더의 3개 스크립트를 순서대로 호출합니다. 엑셀 작성 단계에서는 Anthropic 기본 제공 `xlsx` 스킬의 규칙(서식, 수식 사용, recalc 검증)을 함께 따릅니다.

## 필수 설정 (Setup)

이 플러그인을 사용하려면 **DART Open API 인증키**가 필요합니다.

1. https://opendart.fss.or.kr/ 에서 발급받은 인증키(40자리 영숫자)를 준비합니다.
2. Cowork 환경 변수에 아래 이름으로 등록합니다.

   ```
   DART_API_KEY=발급받은_인증키
   ```

3. 인증키는 절대 스킬 파일이나 산출물(엑셀, 로그)에 직접 하드코딩하지 않습니다. 모든 스크립트는 `os.environ["DART_API_KEY"]`로만 읽습니다.
4. 환경 변수가 설정되어 있지 않으면 스킬은 코드 실행 전에 사용자에게 값을 요청하며, 입력받은 값은 해당 세션의 환경 변수로만 사용하고 대화 로그나 파일에 남기지 않습니다.

## 사용법

Cowork 채팅에서 아래와 같이 요청하면 스킬이 트리거됩니다.

```
삼성전자 재무제표 뽑아줘
LG화학 DART 재무제표 자동화 실행해줘
카카오 최근 12분기, 5개년 재무제표 엑셀로 만들어줘
```

## 산출물

- 파일명: `[기업명]_[YYYYMMDD].xlsx` (YYYYMMDD는 작업 실행일)
- 시트 1: `분기_재무제표` — 최근 12개 분기의 재무상태표·손익계산서·현금흐름표
- 시트 2: `연간_재무제표` — 최근 5개 사업연도(사업보고서 기준)의 재무상태표·손익계산서·현금흐름표

## 커스터마이즈

- 연결/별도 재무제표 선택(fs_div), 분기 수, 연도 수는 `skills/dart-financial-extractor/SKILL.md`의 "설정 영역" 섹션에서 값을 바꿔 조정할 수 있습니다.
