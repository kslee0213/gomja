# Changelog — industry-stock-picker

## 1.0.0 (2026-09-10)

최초 릴리스: "산업 → 종목 추천" 역방향 파이프라인.

- `screen_candidates.py`: candidates.json의 후보(KR/US/JSON)를 일괄 처리 — `--fetch` 시
  기존 추출 플러그인 스크립트로 캐시 수집(연간 5개년 + 진행연도 분기 + 주가) 후,
  valuation-verdict 엔진으로 적정주가·판정·신뢰도를 계산하고 품질·성장 지표와 합쳐
  0~100 점수·순위 산출. 결측 항목은 0점이 아니라 분모 제외 정규화. 후보 단위 실패 격리.
- `build_screening_workbook.py`: 스크리닝_요약(순위표+차트 2개) / 지표_비교(그레이엄
  PER×PBR 수식 판정) / 점수_산식(합계·정규화·최종 수식) / 참고_주의(가정·해자 기입란) 4시트.
- 설계 원칙: 식별자(corp_code/cik) 사전 확정, 후보 전원 동일 가정(상대 비교), 추천 3곳은
  정량 순위 + 해자 정성 리서치로 Claude가 최종 판단(순위와 다르면 사유 명시).
