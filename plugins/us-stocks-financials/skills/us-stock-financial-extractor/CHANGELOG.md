# us-stock-financial-extractor 변경 이력

## v4.0.0 (KR 파이프라인과 동일한 시트 구성·분석 내용으로 전면 확장)

- **지표_분기/지표_연간**: 11개 지표·차트 4개 → KR과 동일한 기본 지표 14개 + 비율 6개 + 임베드 차트 6개.
- **투자분석**: 간이 4개 섹션 → KR과 동일한 A~N 섹션 전체(회사 개황, 재무지표 4그룹, 위험신호 6종, 청산가치, CCC, FCF, 현금흐름 3단, DuPont, ROIC/NOPLAT, 구성비, 외환손익, 연도별 주가 연동, 배당, 투자판단 자동평가 A~E) + 섹션별 차트. 등급 규칙은 KR과 동일(5개년 충족 연수 + 지속개선 승격, 적자 연도 PER/PBR 판정 제외).
- **시트 라벨·레이아웃을 KR과 호환**시켜 investment-thesis-writer(`--unit-label 백만달러 --unit-multiplier 1000000`)와 valuation-verdict를 스크립트 수정 없이 재사용 — "OO 년 분석해줘" 한 마디로 7개 시트(가치평가_결론 포함)가 나온다.
- **fetch_financials.py**: 태그 후보 병합(앞 태그가 비운 연도만 뒤 태그로 보충 — 연도별로 태그가 바뀌는 회사 대응), 같은 (end, 기간)의 정정공시는 filed 최신 우선, **Q4 = 연간−(Q1+Q2+Q3) 파생**(같은 회계연도 분기 3개가 있을 때만, EPS 제외), EPS의 USD/shares 단위 폴백(기존엔 USD 단위만 봐서 EPS가 통째로 비던 버그 수정), 계정 12종 추가(매입채무·단기/장기투자·무형자산·영업권·이익잉여금·투자/재무활동현금흐름·현금증감·외화환산손익 등).
- **fetch_extra_info.py**: 현재가에 더해 월말 종가 7년 이력 + 연도별 주당 배당 합계 수집(연도별 PER/PBR/PSR·N섹션 등급·과거 PER 밴드용). 실패 시 현재가만으로 우아한 성능저하.
- 과거 시가총액은 "현재 상장주식수 × 당시 종가" 근사치임을 시트에 명시. 대주주·자기주식은 SEC proxy/13F 영역이라 범위 밖임을 명시.
- 검증: 합성 SEC 픽스처(FAKE)로 전체 파이프라인(수집→워크북→투자판단 종합→가치평가→결론) 실행, LibreOffice 재계산에서 N/A(데이터 없음 표시) 외 수식 오류 0건, Q4 파생값·단위 환산·주식수 역산 수치 검증. 실제 기업 데이터 검증은 이 개발 환경에서 SEC 네트워크가 차단되어 못 했으므로 첫 실사용 시 missing_indicators와 값을 확인할 것.

## v3.0.0 (SEC EDGAR 전환)

재무제표 소스를 yfinance(비공식, 403 차단 위험)에서 SEC EDGAR CompanyFacts API로 전환. BS 스냅샷이 연간 축에 섞이는 버그와 EPS 백만달러 환산(PER 100만 배) 버그를 수정. PER/PBR/PSR을 완제품 값 대신 직접 수식으로 계산. (상세는 리포 이력 참고)
