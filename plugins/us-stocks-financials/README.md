# us-stocks-financials

미국 나스닥/뉴욕증권거래소 상장 기업의 재무제표를 yfinance로 수집해 엑셀 분석 파일을 생성합니다. `dart-kospi-financials`(한국 DART 버전)와 같은 설계 원칙(원본데이터 시트 + 수식 기반 감사 가능성)을 따르되, yfinance의 데이터 특성에 맞게 조정했습니다.

> v2.0.0에서 전면 재작성했습니다. 이전 버전은 문서가 광고한 기능의 상당수가 실제 코드에 없었고 여러 버그가 있었습니다 — 자세한 내용은 `SKILL.md`의 "v2.0.0 (전면 재작성)" 참고.

## 특징 (실제 구현된 것만)

- **yfinance 기반**: API 키 불필요. 다만 공식 API가 아니라 Yahoo Finance 데이터 스크레이핑이라 DART보다 데이터 안정성이 낮습니다(분기 4~5개, 연간 4개 정도만 제공되는 게 보통).
- **원본데이터 시트 + 수식 참조**: 모든 재무제표·지표 셀이 원본데이터 시트를 참조하는 수식으로 만들어져 감사 가능합니다(계산된 숫자를 그대로 박아넣지 않습니다).
- **캐싱**: 재실행 시 캐시를 실제로 읽어서 재사용합니다.
- **다중 기업 비교**: 여러 기업의 실제 시계열 데이터를 나란히 비교합니다.

## 필수 설정

```bash
pip install yfinance openpyxl --break-system-packages
```

## 사용 예시

```
애플 재무제표 뽑아줘          → AAPL(매핑 목록에 있으면 자동, 없으면 Ticker 직접 요청)
테슬라 년 분석해줘            → TSLA 연간 분석
마이크로소프트, 구글 비교해줘  → MSFT, GOOGL 비교
```

## 구성

### 스킬
- `us-stock-financial-extractor`: 재무 데이터 수집 → 엑셀 생성

### 스크립트 (5개)
| 스크립트 | 역할 |
|---|---|
| `ticker_lookup.py` | 기업명(38개 고유 기업 매핑) → Ticker 변환. 없으면 직접 입력 티커의 실존 여부 검증 |
| `fetch_financials.py` | yfinance로 재무제표(BS/IS/CF) 수집·캐시 |
| `fetch_extra_info.py` | 현재 주가·PER·PBR·배당 등 수집·캐시 |
| `build_workbook.py` | 단일 기업 엑셀 생성(캐시를 실제로 읽음) |
| `build_comparison_workbook.py` | 여러 기업 비교 엑셀 생성(실제 시계열 기반) |

## 생성되는 엑셀 파일

### 시트 구성
- **분기_재무제표**: 있는 만큼의 분기(보통 4~5개, yfinance 데이터 제약)
- **연간_재무제표**: 있는 만큼의 연도(보통 4개)
- **지표_분기 / 지표_연간**: 재무비율 11개 + 라인차트 4개
- **투자분석**: 재무비율 요약, 위험신호, 주가 연동 지표, 간이 투자판단(4개 섹션)
- **원본데이터**: yfinance raw 값(숨김). 다른 모든 시트가 이 시트를 수식으로 참조

## yfinance의 제약 (정직하게 안내)

- 분기 데이터는 보통 4~5개, 연간은 보통 4개년까지만 제공됩니다. "12분기/5개년"을 요청해도 있는 만큼만 채워집니다.
- 비공식 스크레이핑 특성상 계정이 가끔 비거나 필드명이 바뀔 수 있습니다.
- 과거 시점의 PER/PBR(연도별 값)은 계산하지 않습니다 — 현재 시점 스냅샷만 제공합니다.
